# Security and data boundaries

This repository is a static project showcase. No application backend, model weights, private signing material, personal galleries or provider credentials belong here.

Do not attach secrets or private biometric samples to issues or pull requests. Report a suspected secret exposure using GitHub's private vulnerability reporting when enabled; otherwise contact the repository owner without including secret values in a public issue.

The interactive demo uses fictional case data. Local file hashing reads bytes on the visitor's device without uploading them. Only a theme preference is stored locally; review notes remain in the current page session. External links and the hosting provider have their own policies.
