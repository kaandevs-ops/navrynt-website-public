# Contributing

1. Open an issue describing the documentation, layout or demo-interaction change.
2. Keep all sample case records fictional and label illustrative outputs.
3. Preserve source attribution and research limitations for recorded media.
4. Never add private application code, model weights, credentials or real biometric galleries.
5. Run `python3 scripts/validate.py` and syntax checks for any changed JavaScript.
6. Verify keyboard access and a narrow viewport when changing interactive UI.

Changes to this showcase do not certify the private application's models, providers or deployment behavior.
